# Imágenes de Campos del Este Fase III

La aplicación usa los tres archivos de fotografía, el logo y el plano PDF que se subieron al repositorio. Se conservan los nombres actuales, incluidas las extensiones dobles:

- `logo-campos-del-este.png.jpeg` — logo original aprobado
- `fase3-aerea-1.jpg.jpeg` — fotografía aérea principal
- `fase3-aerea-2.jpg.jpeg` — fotografía aérea secundaria
- `fase3-aerea-3.jpg.jpeg` — fotografía aérea secundaria
- `plano-fase3.pdf.pdf` — plano de urbanización en PDF

No existe una cuarta fotografía y no se debe inventar ni sustituir por imágenes de otro barrio.

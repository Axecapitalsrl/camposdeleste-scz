# Imágenes de Campos del Este Fase III

La aplicación usa los tres archivos de fotografía y el logo que ya se subieron al repositorio. Se conservan sus nombres actuales, incluyendo las extensiones dobles:

- `logo-campos-del-este.png.jpeg` — logo original aprobado
- `fase3-aerea-1.jpg.jpeg` — fotografía aérea principal
- `fase3-aerea-2.jpg.jpeg` — fotografía aérea secundaria
- `fase3-aerea-3.jpg.jpeg` — fotografía aérea secundaria
- `plano-fase3.pdf` — plano de urbanización en PDF (pendiente de subir)

No existe una cuarta fotografía y no se debe inventar ni sustituir por imágenes de otro barrio. El plano se mostrará mediante un visor PDF del navegador una vez que el archivo original esté disponible.
